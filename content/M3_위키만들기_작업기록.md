## 6단계 — GitHub push ✅ (2026-06-28 완료)

### (가) 커밋
- 커밋 명령이 처음엔 **PowerShell에서 깨짐**: `git commit -m "$(cat <<'EOF'...)"` 같은 여러 줄(heredoc) 문법은 윈도우에서 안 먹음 (`malformed syntax` 에러).
- **해결:** 영어 한 줄로 간단히 커밋.
  ```
  git commit -m "M3: add archive notes and Quartz setup"
  ```
- 결과: **커밋 f42d9a3 — 8개 파일, 643줄 추가.**

### (나) PAT(토큰) 발급 — 여기서 가장 헤맴
- **Confirm access(본인 인증):** GitHub이 토큰 발급 전 이메일 인증을 요구.
  - ⚠️ **Gmail 저장공간이 100% 꽉 차서** 인증 메일이 잘 안 들어옴 (이게 진짜 원인이었음).
  - 작은 텍스트 메일은 가끔 들어와서, "[GitHub] Sudo email verification code"의 8자리 코드로 통과.
  - 처음 코드는 만료/오타로 실패 → 새 코드 받아서 통과. (코드 보면 바로 입력! 15분 유효.)
- **토큰 설정:** Note `quartz push`, Expiration `30 days`, Scopes **`repo` 하나만** 체크.
  - ⚠️ Settings → Tokens **(classic)** 쪽. OAuth Apps 아님.
- ⚠️ **실수 교훈:** 토큰을 복사한 뒤 목록에서 **Delete를 눌러 토큰을 무효화**해버림 → push 실패 → 재발급.
  - **토큰은 push 끝날 때까지 지우지 말 것!** 복사만 하고 화면은 그대로 둔다.

### (다) push
- Claude Code에서 `!`로 직접 실행 (자격증명 입력 받으려면 필요):
  ```
  ! git -C "C:\Users\김민석\Documents\quartz" push origin v5
  ```
- **"Connect to GitHub" 로그인 팝업**이 뜸 → **Token 탭** 선택 → 메모장의 토큰(`ghp_...`) 붙여넣기 → Sign in.
  - (또는 "Sign in with your browser"로도 가능)
- 결과: **`9cf87ff..f42d9a3  v5 -> v5` — Push 성공!** 🎉
  - 확인: `github.com/a01026886152-prog/quartz` → content에 M1·M2·README·index.md.

### (라) 보안 마무리
- push 후 토큰 정리됨 (GitHub 토큰 목록 "No personal access token created" = 비어 있음).
- 메모장에 저장한 토큰 글자도 삭제.

## 🔜 다음에 이어서 할 일 — 7단계 Cloudflare Pages (마지막)

> **⚠️ 시작 전 꼭 확인:** Cloudflare 가입에 **이메일 인증**이 필요한데 **Gmail이 100% 꽉 참**.
> → **Gmail 용량을 먼저 정리하거나**, 안 꽉 찬 **다른 이메일(네이버/다음 등)로 가입**할 것. 안 그러면 인증 메일에서 또 막힘.

### 순서
1. `dash.cloudflare.com/sign-up` → 가입 (이메일+비번. GitHub 가입 버튼은 없음.)
   - 인증 메일 받아서 계정 활성화.
2. Cloudflare 대시보드 → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
3. GitHub 연동 (Authorize 화면 나오면 권한 확인 후 승인) → `a01026886152-prog/quartz` 레포 선택, 브랜치 `v5`
4. **빌드 설정:**
   - Framework preset: `None` (또는 Quartz 있으면 그걸로)
   - **Build command:** `npx quartz build`
   - **Build output directory:** `public`
5. **Save and Deploy** → 1~2분 빌드 → **라이브 URL `https://(이름).pages.dev` 생성 = M3 완료!** 🏁

### 참고
- 이 `*.pages.dev` 주소가 나중에 **M5(내 사이트)** 에서 위키 링크로 들어감.
- 배포 후 위키 첫 페이지가 안 뜨거나 깨지면 → base URL을 실제 pages.dev 주소로 맞춰야 할 수 있음 (`quartz.config.yaml` 또는 Cloudflare 환경변수). 그때 챗 Claude에 문의.

## 핵심 개념 메모

- **PowerShell에선 여러 줄 문법(heredoc, `$(...)`) 쓰지 말 것.** 커밋 메시지는 `git commit -m "영어 한 줄"`로.
- **토큰(PAT)은 push 끝날 때까지 절대 지우지 말 것.** 한 번 화면 벗어나면 다시 못 보고, Delete하면 무효가 됨.
- **Gmail 100% 꽉 참 = 인증 메일 못 받는 근본 원인.** GitHub·Cloudflare 등 메일 인증이 다 막힘 → 용량 정리 필요(별도 과제).
- **Quartz v5 셋업 정석:** `create` → `plugin install --from-config` → `build --serve`. create는 한 번만.
- **localhost = 내 PC에서만.** 인터넷 공개는 Cloudflare(7단계)에서.
- **에러는 원래 나는 것.** 신순화님 잘못 아님.
