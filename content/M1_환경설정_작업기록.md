## 1. 시작 상태 (점검 결과)

PowerShell에서 환경을 점검했을 때, 작업에 필요한 도구가 거의 다 없었음.

| 항목 | 시작 상태 |
|---|---|
| 셸 (PowerShell) | ✅ 있음 (5.1, Windows 기본) |
| Git | ❌ 없음 |
| Node | ❌ 없음 |
| VSCode | ❌ 없음 |
| Obsidian | ❌ 없음 |

> **메모:** 윈도우 기본 셸은 PowerShell. bash/zsh 문법(`~`, `&&`)은 그대로 안 먹힐 수 있어서, PowerShell 방식으로 바꿔서 진행함.

---

## 2. 설치한 도구 (최종 상태)

모두 `winget`(윈도우 기본 설치 도구)으로 설치. 설치 후엔 **PowerShell 창을 새로 열어야** 명령이 인식됨.

| 도구 | 버전 | 설치 명령 |
|---|---|---|
| Git | 2.54.0 | `winget install --id Git.Git -e --source winget` |
| Node | v24.18.0 | `winget install --id OpenJS.NodeJS.LTS -e --source winget` |
| npm | 11.16.0 | (Node와 함께 설치됨) |
| VSCode | 1.126.0 | `winget install --id Microsoft.VisualStudioCode -e --source winget` |
| Obsidian | 1.12.7 | `winget install --id Obsidian.Obsidian -e --source winget` |
| Claude Code | 2.1.191 | `npm install -g @anthropic-ai/claude-code` |

## 3. 막혔던 지점과 해결법

작업하면서 빨간 에러가 몇 번 났지만, 대부분 무해하거나 간단히 해결됨. 기록해두면 다음에 안 당황함.

### (1) 설치 직후 "인식 안 됨" 에러
- **증상:** 도구를 막 깔았는데 `git`/`node`/`code`가 "인식되지 않습니다"로 나옴
- **원인:** PowerShell이 새로 깐 도구를 아직 모름 (창을 안 닫아서)
- **해결:** PowerShell 창을 **완전히 닫고 새로 열기** → 거의 다 해결됨

### (2) npm 보안 정책 에러 (PSSecurityException)
- **증상:** `npm -v` 칠 때 "스크립트를 실행할 수 없으므로 npm.ps1을 로드할 수 없습니다"
- **원인:** 윈도우가 기본적으로 `.ps1` 스크립트 실행을 막아둠
- **해결:**
  ```powershell
  Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
  ```
  (CurrentUser 범위 + RemoteSigned = 개발 환경 표준 설정. 시스템 전체를 건드리지 않아 안전함)

### (3) "다음"을 PowerShell에 타이핑한 오타
- **증상:** PowerShell에 `다음`을 쳤더니 "용어가 인식되지 않습니다" 빨간 에러
- **원인:** "다음"은 Claude(채팅)한테 하는 신호인데, 컴퓨터한테 명령하는 곳(PowerShell)에 침
- **교훈:** **PowerShell = 컴퓨터한테 명령** / **채팅창 = Claude한테 말** — 구분하기
- **무해함:** 그냥 허공에 친 거라 아무 문제 없음

### (4) 설치 중 화면이 멈춘 것처럼 보임
- **증상:** "설치 관리자가 관리자 권한으로 실행을 요청합니다"에서 멈춘 듯
- **원인:** 화면 갱신이 늦은 것뿐. 실제론 UAC 팝업 대기 중이거나 설치 진행 중
- **해결:** UAC 팝업 뜨면 "예", 그래도 멈춘 듯하면 1~2분 기다리거나 Enter 한 번

### (5) winget warn / notice (노란 글씨)
- **증상:** `npm warn allow-scripts`, `npm notice New version available` 등
- **판단:** **경고/안내일 뿐.** 빨간 `error`만 아니면 정상. 무시해도 됨

## 4. 만든 것

### 작업 폴더
```
C:\Users\(사용자)\ansungact-ai
```
생성 명령 (PowerShell 방식):
```powershell
cd ~
mkdir ansungact-ai
cd ansungact-ai
```

### CLAUDE.md
폴더 안에 `CLAUDE.md` 생성. 이 파일이 Claude Code를 띄울 때마다 자동으로 읽혀서, 매번 "내가 누구인지" 설명할 필요가 없게 해줌.

한글이 안 깨지게 `-Encoding utf8` 옵션으로 저장하는 게 포인트:
```powershell
@'
...(내용)...
'@ | Out-File -FilePath CLAUDE.md -Encoding utf8
```

담은 내용: 이름/역할/책임연구원/기간, 만들 5종 자산, Claude에게 부탁하는 톤, 지금 단계(M1), 현장 문제.

## 5. Claude Code 시동 + 검증

1. 폴더 안에서 `claude` 실행
2. 테마 선택 (Dark mode)
3. 로그인 방식: **1. Claude account with subscription** (구독 계정, 추가 비용 없음)
4. 브라우저 자동 로그인 → "Claude Code 설정이 완료되었습니다"
5. 폴더 신뢰 확인 → **Yes, I trust this folder**
6. 대화 화면 진입 ✅

### 검증 질문
```
내가 누구고 지금 뭘 하고 있는지 말해봐.
```

→ Claude Code가 CLAUDE.md를 읽고 **신순화 / 안성 지역활동 아키비스트 / 5종 자산 / M1 진행 중**을 정확히 답함.
→ 동시에 "메모리는 아직 없고, 이 내용은 전부 CLAUDE.md에서 가져온 것"이라고 **솔직하게** 밝힘 (톤 규칙 "모르면 모른다 먼저" 작동 확인).

## 6. 챗 Claude vs Claude Code — 차이

| | 챗 Claude | Claude Code |
|---|---|---|
| 컨텍스트 | 매번 설명 필요 | 폴더 들어가면 CLAUDE.md 자동 인식 |
| 파일 작업 | 직접 못 함 | PC 파일 읽기/편집/실행 가능 |
| 쓰는 곳 | 웹/앱 채팅창 | PowerShell 안 |
