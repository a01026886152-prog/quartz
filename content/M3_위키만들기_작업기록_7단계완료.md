## 핵심 개념 메모 (7단계에서 새로 배운 것)

- **Cloudflare는 이제 Pages를 Workers로 통합함.** Pages 전용 입구가 안 보이면 그게 정상. Workers 흐름으로 진행하되 **`wrangler.toml`로 보완**.
- **wrangler.toml 필수 내용 (Quartz 정적 사이트 배포용):**
  ```toml
  name = "quartz"
  compatibility_date = "2026-06-28"
  pages_build_output_dir = "public"

  [assets]
  directory = "./public"
  ```
  - `pages_build_output_dir` 와 `[assets] directory` **둘 다** 있어야 Deploying까지 통과.
- **Deploy command 칸:** Workers 흐름은 이걸 필수로 요구 → `npx wrangler deploy` 넣기.
- **환경변수는 대문자!** `NODE_VERSION` (소문자 `node_version`은 인식 안 됨).
- **자동 재배포:** GitHub에 push만 하면 Cloudflare가 변경 감지 → 자동으로 다시 빌드·배포. (Deploy 버튼 안 눌러도 됨.)
- **PAT 토큰은 push 끝나면 즉시 폐기** (`github.com/settings/tokens` → Delete + 메모장 글자 삭제). URL에 끼워 넣으면 화면에 노출되니 더더욱.
- **실제 주소는 `.workers.dev`** (예상한 `.pages.dev` 아님). 헷갈리지 말 것.
